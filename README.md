# Libertas Tours — Website

Website voor **De Libertas** — een historisch opleidingsschip van 38 meter dat game-based trainingen, reflectie-coaching en leiderschapsprogramma's aanbiedt op het water.

🌐 **Domein:** [libertas.tours](https://libertas.tours)

---

## Pagina's

| Pagina | Bestand | Beschrijving |
|--------|---------|-------------|
| Home | `index.html` | Hero, filosofie, drie programma's, waarom De Libertas |
| Bemanning | `bemanning.html` | Ruth Lachaert & IJsbrand Overmaat |
| Het Schip | `het-schip.html` | De Libertas: specs, historie |
| Agenda | `agenda.html` | Trainingsdata |
| Locaties | `locaties.html` | Vaarlocaties |
| Service & Tarieven | `service-en-tarieven.html` | Diensten en prijzen |
| Contact | `contact.html` | Contactformulier + offerte aanvragen |

## Technologie

- **HTML5 + Tailwind CSS** (via CDN)
- **Geen build-stappen** — direct te openen in de browser
- **Hosting:** Hostinger (statische bestanden)
- **Contactformulier:** Formspree.io
